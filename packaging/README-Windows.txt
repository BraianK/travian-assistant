Travian Kingdoms Assistant — Windows

1. Rozpakuj całe archiwum do wybranego folderu.
2. Uruchom TravianAssistant.exe.
3. Kliknij „Uruchom przeglądarkę” i zaloguj się ręcznie do Traviana.
4. Wróć do aplikacji i kliknij „Połącz”.

Python ani osobna baza danych nie są wymagane. Aplikacja tworzy bazę,
ustawienia i kopie zapasowe automatycznie w:
%LOCALAPPDATA%\Travian Kingdoms Assistant

Profil przeglądarki jest przechowywany lokalnie w tym samym katalogu.
Nie udostępniaj folderu danych ani profilu — zawierają prywatną sesję gry.

Wymagana jest zainstalowana przeglądarka Chrome, Edge, Opera lub Opera GX.
Przy pierwszym uruchomieniu Windows może wyświetlić ostrzeżenie SmartScreen,
ponieważ program nie jest podpisany certyfikatem wydawcy.
